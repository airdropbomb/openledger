# Openledger Auto Bot

- ## Installation

1. Clone the repository:
```
git clone https://github.com/airdropbomb/openledger.git
cd openledger
```

2. Install the required packages:
```
npm install
```

## Setup

![Screenshot_139](https://github.com/user-attachments/assets/04c95f20-18bc-4591-887b-f86d2636ba95)


3. Open `tokens.txt` file in the same directory as the script with one token per line:
```
nano tokens.txt
```

4. Open `proxy.txt` file with one proxy per line (must need)
```
nano proxy.txt
```

5. Run the bot:
```
node main.js
```
